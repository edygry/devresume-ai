# DevResume AI

AI-powered resume optimization for software engineers.

## Features

- **Resume Scoring**: Get an overall score (0-100) with section breakdowns
- **Specific Improvements**: Actionable suggestions with examples
- **Job Matching**: Compare your resume against job descriptions
- **LinkedIn Headline**: AI-generated headlines that get more views
- **Cover Letters**: Premium feature for tailored cover letters
- **Salary Insights**: Know your worth based on experience

## Tech Stack

- Vue 3 + Vite
- Pinia for state management
- Vue Router for navigation
- Gemini AI for analysis

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push to gh-pages branch for GitHub Pages deployment.

## Pricing

- **Free**: Basic analysis (score, improvements, headline)
- **Premium ($9)**: Job matching, cover letters, salary insights
- **Pro ($29)**: Full rewrite, LinkedIn review, consultation
